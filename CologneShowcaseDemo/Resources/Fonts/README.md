# Brand fonts

The supplied font packages are bundled and registered through `UIAppFonts`.

- Aeonik Soft Pro: body copy, controls and utility text. All 16 supplied styles are included.
- Exposure `[-10]`: display headings. Regular and Italic are included.

SwiftUI uses the fonts' PostScript names (`AeonikSoftPro-*` and
`Exposure-10-*`) rather than their filenames.
